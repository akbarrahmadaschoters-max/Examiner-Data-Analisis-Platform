# Platform Penilaian Terpadu

Executive brief untuk C-level tentang sentralisasi data penilaian speaking & writing IELTS.

Isi halaman:

1. Ringkasan dan angka utama
2. Problem definition
3. Kondisi sekarang vs tujuan
4. Grand design (dengan lampiran diagram Excalidraw)
5. Matriks akses divisi (Examiner, Ops CMS, Akademik, SSO)
6. Target setelah improvement
7. Roadmap H1 2027 dan keputusan yang diminta

## Struktur

```
index.html                    halaman utama (HTML + CSS + JS dalam satu file)
excalidraw-grand-design.webp  lampiran diagram
```

## Menjalankan

Buka `index.html` langsung di browser. Tidak perlu build atau dependency.

## Publish dengan GitHub Pages

1. Push folder ini ke repository GitHub.
2. Buka Settings → Pages.
3. Pada Source pilih **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Halaman akan tersedia di `https://<username>.github.io/<nama-repo>/`.

> Catatan: jika repository publik, isi halaman ini bisa dilihat siapa saja. Gunakan repository private jika datanya internal.
